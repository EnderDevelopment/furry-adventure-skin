# Minecraft Texture

Furry Adventure Skin is a 64×64 pixel-art Minecraft texture source featuring a fox-inspired furry design in orange, cream, and brown, with green accents. It is provided as an SVG file and must be exported as a PNG before use as a Minecraft skin.

## Install

1. Open `assets/textures/fox_furry_skin.svg` in an SVG editor or converter.
2. Export it as a 64×64 PNG, preserving transparency and the pixel-art edges.
3. In your Minecraft skin management interface, choose the option to upload or import a custom skin and select the PNG.

## Use

1. Preview the imported skin on your character.
2. Select the model type requested by your Minecraft skin interface.
3. Save or apply the skin, then check it in-game.
